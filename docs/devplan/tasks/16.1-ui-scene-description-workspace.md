## Goal
Implementar el primer workspace de producto para describir una escena en
lenguaje natural, traducirla a un `scene brief` estructurado y dejarla lista
para el resto del pipeline.

## Minimal Context
La fase `15` define el shell y la capa comun de adaptacion. Esta fase debe
consumir esa base para resolver el primer paso real del flujo UX:

- capturar intencion
- identificar tono, assets y restricciones
- mejorar el input humano para consumidores finales
- publicar un `scene brief` reutilizable por los siguientes pasos

Fuera de alcance:

- crear aun los assets reales o la estructura completa de escena
- abrir un modelo de prompts ad hoc por backend
