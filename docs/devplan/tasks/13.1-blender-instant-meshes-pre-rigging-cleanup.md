## Goal
Implementar la infraestructura reusable para que `OpenClaw` orqueste, con un
solo entrypoint canonico, el flujo:
`source model -> Blender cleanup -> Instant Meshes -> cleaned/remeshed handoff`
orientado a usuarios principiantes y Linux local.

## Minimal Context
El repo ya tiene contrato de runner, `runner-action.sh`, wrapper de `Blender`
y convenciones de evidencia. Falta una ruta canonica para cleanup pre-rigging
de humanoides AI-generated donde `OpenClaw` orquesta y `Blender` +
`Instant Meshes` hacen el trabajo de geometria.

Esta tarea cubre infraestructura y validacion inicial, no rigging final.

## Required Change
- Add a canonical orchestration path for cleanup pre-rigging using existing
  runner infrastructure.
- Keep responsibilities explicit:
  `OpenClaw` orchestration and UX, `Blender` cleanup operations in background
  Python, `Instant Meshes` remeshing stage.
- Support first operations set:
  apply scale/rotation, center character, place lowest point on `Z=0`,
  recalculate normals, remove loose geometry when safe, detect and optionally
  remove very small floating parts, join mesh parts only when justified,
  reduce polygons only above conservative threshold, export to `Instant
  Meshes`, invoke `Instant Meshes`, collect remeshed output.
- Support `auto` and `debug` modes under the same entrypoint.
- Publish evidence with before/after model refs, command logs, and cleanup
  report.
